# Voice-First Government Scheme & Public Resource Navigator

An AI-powered, multilingual, voice-first assistant designed to help citizens easily discover and access government schemes, welfare programs, and public resources — with a strong focus on inclusion, accessibility, and low-bandwidth usability.

---

## 🚀 Overview

Millions of citizens, especially in rural and low-literacy communities, are unaware of government schemes they are eligible for due to complex portals, language barriers, and digital literacy gaps.

This project solves that problem by providing a **conversational, voice-driven AI system** that:
- Asks simple questions
- Identifies eligible schemes
- Explains benefits in plain language
- Guides users through application steps

---

## 🎯 Key Features

- 🎙️ **Voice-First Interaction** (Primary Interface)
- 💬 Text Chat Fallback
- 🌐 Multilingual Support (English + Regional Languages)
- 🧠 AI-Powered Eligibility Discovery
- 📄 Document Checklist & Application Guidance
- 🏢 Nearest Government Office / Portal Suggestions
- 📶 Low-Bandwidth Optimized
- 🔒 Privacy-First (No Personal Data Storage)

---

## 🎥 Demo

> This project is designed for voice-first interaction and low-bandwidth environments.

### Demo Flow:
1. User asks (via voice): *“Which government schemes can I get?”*
2. AI asks basic questions (age, income, occupation, location)
3. Eligible schemes are identified
4. Benefits and application steps are explained in simple language


## 🛠️ Tech Stack

- **Backend:** Python (Flask)

- **Speech:** Speech-to-Text & Text-to-Speech
- **Frontend:** Lightweight Web UI (Mobile-first)
- **Cloud:** AWS
